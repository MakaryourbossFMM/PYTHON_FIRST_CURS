## Что изученно

1. Ветвление — конструкция, которая выбирает действия по результату условия. Если условие равно True, выполняется один блок; если False, этот блок пропускается или выбирается другая ветка.
2. ОПЕРАТОР IF. if переводится как «если». Блок под ним выполняется только при истинном условии.
3. ВЕТКА ELSE. else означает «иначе» и выполняется, когда условие if ложно. У else нет собственного условия.
4. ДОПОЛНИТЕЛЬНЫЕ ВЕТКИ ELIF. elif означает «иначе, если». Он добавляет ещё одну проверку между if и необязательным else.

#### Порядок проверок 
Python проверяет ветки сверху вниз и останавливается на первой истинной. Это относится ко всей связанной цепочке if / elif / else.

1. Сначала проверяется условие if. Если оно истинно, выполняется его блок: условия elif уже не вычисляются, а else пропускается.
2. Если if оказался ложным, условия elif проверяются по очереди сверху вниз.
3. После первого истинного elif его блок выполняется: условия оставшихся elif уже не вычисляются, а else пропускается.
4. Если все условия ложны, выполняется else. Если его нет, вся цепочка пропускается.

Правило цепочки
Выполняется не более одной ветки. После первой истинной ветки остальные условия не проверяются.

#### Цепочка отличается от нескольких отдельных if. Каждый отдельный if проверяется независимо, поэтому могут выполниться сразу несколько блоков.
два независимых if
```python
number = 10
if number > 0:
    print("Положительное число")

if number > 5:
    print("Число больше пяти")
Вывод:
Положительное число
Число больше пяти
```
